# Правила статусов

## Работы: видимая модель строго из четырех статусов

- `Не начато` → `NOT_STARTED` → 0%
- `В работе` → `IN_PROGRESS` → 50%
- `На согласовании` → `APPROVAL` → 90%
- `Выполнено` → `COMPLETED` → 100%

Другие формулировки могут приниматься только как legacy input. В clean/working DOCX они не выводятся.

`Факт не подтвержден` и `Требует подтверждения` не являются рабочими статусами. Неопределенность хранится отдельным признаком/комментарием.

## Риски

`Открыт`, `В обработке`, `Реализован`, `Закрыт`.

## Оплаты

Платежная модель независима от рабочих статусов: `Оплачен`, `Подтвержден`, `Не оплачен`, `Требует подтверждения`, `Не наступил срок`.
