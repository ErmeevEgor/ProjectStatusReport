# Правила статусов

## Работы: видимая модель строго из четырех статусов

- `Не начато` → `NOT_STARTED` → 0%
- `В работе` → `IN_PROGRESS` → 50%
- `На согласовании` → `APPROVAL` → 90%
- `Выполнено` → `COMPLETED` → 100%

Другие формулировки могут приниматься только как legacy input и должны быть нормализованы к четырём видимым статусам.

`Факт не подтвержден`, `Требует подтверждения`, `На проверке`, `На приемке` не являются отдельными видимыми рабочими статусами. Неопределённость хранится отдельным признаком, комментарием и/или confidence источника.

## Риски

Риск/проблема/отклонение используют отдельный жизненный цикл, например: `Открыт`, `В обработке`, `Реализован`, `Закрыт`.

## Оплаты

Платежная модель независима от рабочих статусов: `Оплачен`, `Подтвержден`, `Не оплачен`, `Требует подтверждения`, `Не наступил срок`.

Handy Status ID для визуализации этих доменов нельзя смешивать между работами, оплатами и рисками даже при совпадении текста.
