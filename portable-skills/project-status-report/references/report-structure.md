# Структура ОСП

Документ всегда состоит ровно из четырех страниц A4 landscape.

## Страница 1. Резюме по проекту

### Паспорт
- Заказчик
- Проект
- Руководитель проекта от Заказчика
- Основание
- Дополнительное соглашение
- Номер отчета
- Руководитель проекта от Исполнителя
- Отчетный период

### Сводные данные
- Плановый период этапа
- Фактическое начало / завершение
- Этап проекта
- Общий статус проекта

"Общий статус проекта" — 4–6 управленческих тезисов:
1. где находится проект;
2. что завершено;
3. что делается / что дальше;
4. есть ли отклонение по срокам;
5. состояние оплат;
6. ключевой риск/зависимость.

### План и статус этапов

Колонки:
- Этап
- Трудоемкость
- Бюджет
- Статус
- Коэффициент статуса
- Расчетное освоение
- Комментарий

### Итоговый прогресс

Показать:
- общий бюджет;
- расчетное освоение;
- остаток;
- процент выполнения.

### План / факт оплат

Колонки:
- Платеж
- Сумма
- План / основание по ДС
- Плановая дата / срок
- Факт
- Дата факта
- Статус

Источник не пишется в видимой таблице.

## Страница 2. Данные по задачам

Колонки:
- №
- Задача / результат
- Ответственный
- Статус
- Бюджет
- Расчетное освоение
- Плановое начало
- Плановое завершение
- Фактическое завершение
- Комментарий

Если задача не имеет собственной стоимости, оставлять бюджет пустым; не распределять стоимость искусственно.

## Страница 3. Риски проекта

Колонки:
- Дата
- Тип
- Отклонение / риск
- Вероятность / факт
- Влияние
- Влияние на проект
- Корректирующие мероприятия
- Результат / принятое решение
- Статус

Тип:
- РИСК
- ПРОБЛЕМА
- ОТКЛОНЕНИЕ

Таблица должна помещаться в ширину страницы. Использовать компактный шрифт и фиксированные ширины.

## Страница 4. Ключевые вопросы и проблемы

### Health check

Вопросы:
1. Изменился состав и границы задач?
2. Есть отклонение от плановых сроков?
3. Есть проблемы планирования работ?
4. Есть организационные проблемы?
5. Есть технические проблемы?
6. Есть проблемы согласования / утверждения документов?
7. Есть открытые риски проекта?

Ответ на п.7 выводится автоматически из страницы рисков.

### Открытые вопросы / действия

Колонки:
- Открытый вопрос / действие
- Необходимое действие / решение
- Ответственный
- Срок
- Статус / результат

Просроченный срок не скрывать.
