# ProjectStatusReport v0.7.0

## Главное изменение — previous-first ОСП

Предыдущий ОСП теперь является основным структурным шаблоном следующего отчета. При повторном формировании по тому же проекту скилл не должен заново придумывать структуру страниц и таблиц: обновляются актуальные данные внутри существующей совместимой структуры.

## Страница 2

Fallback-таблица `Данные по задачам` исправлена:
- `№` заменено на `Код задачи`;
- `Наименование` и `Задача` разделены;
- `План начала` и `План завершения` — отдельные колонки;
- сохраняется договорный baseline и стоимостный расчет прогресса без двойного учета.
