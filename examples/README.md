# Обезличенный пример

`sample-report-data.json` показывает структуру данных, которую LLM формирует перед рендерингом.

Пример не содержит данных реального заказчика.
Он включает три договорных этапа, отдельные operational items, управленческий
вывод по рискам, финансовое наблюдение, следующий контрольный ориентир и оба
новых сценария оплаты: `project_confirmed` и `missing`.

Для проверки:

```bash
python -m project_status_report.cli examples/sample-report-data.json --out output --name sample
```

Ожидаемый расчетный прогресс:

- 20 000 × 100% = 20 000
- 30 000 × 90% = 27 000
- 50 000 × 50% = 25 000

Итого: `72 000 / 100 000 = 72,0%`.

Случайно заполненный бюджет operational item намеренно не входит в формулу.
